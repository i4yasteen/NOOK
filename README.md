# NOOK - Cafeteria e Sebo

Sistema web para gerenciamento de uma cafeteria e sebo, desenvolvido com NestJS, TypeORM e EJS.

O projeto está organizado em módulos (Livro, Evento, Cliente, Funcionário, Reserva e Participar). Cada módulo segue o padrão do professor, com entity, DTOs, service, controller e views.

As views utilizam EJS com Bootstrap, e o banco de dados é configurado via TypeORM com sincronização automática em desenvolvimento.
